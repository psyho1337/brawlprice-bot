# Brawl Stars Account Appraiser Bot

1. `pip install -r requirements.txt`
2. Скопируй `.env.example` в `.env` и заполни токены.
   Ключ Brawl Stars API привязывается к IP сервера, на котором запускается бот.
3. `python main.py`

## Картинки
- `assets/logo.jpg` — приветственное фото
- `assets/example_tag.jpg` — подсказка, где искать тег

## Настройка цен (только для ADMIN_IDS)
- `/prices` — текущие цены
- `/setprice brawler 20` — изменить цену
- `/stats` — статистика
Наценка задаётся `MARKUP` в `.env`.

## Менеджер и заявки
- `MANAGER_USERNAME` в `.env` — кому ведут кнопки «Продать» и «Уточнить у менеджера» (по умолчанию psyhode3ic).
- `MANAGER_CHAT_ID` (необязательно) — ID менеджера: бот будет присылать ему заявки с ответами продавца.
  Менеджер должен хотя бы раз нажать /start у бота.

## Админ-панель и менеджеры
- `/admin` (только `ADMIN_IDS`): статистика, заявки, цены кнопками, рассылка, баны, экспорт в CSV.
- `MANAGER_IDS` в `.env` — менеджеры. Получают заявки с кнопками «В работе / Куплено / Отказ» и команду `/leads`,
  но в админ-панель попасть не могут. Каждый должен хотя бы раз нажать /start у бота.

## Этап 4: подписка, бонусы, inline, языки
- `REQUIRED_CHANNEL=@канал` в `.env` включает обязательную подписку (бот должен быть админом канала).
- Бонусы: рефссылка `t.me/бот?start=ref_ID`, промокоды создаются в `/admin` → «🎟 Промокоды».
  Размер реферального бонуса: цены `ref_bonus_per` и `ref_bonus_max` (0 = выключить).
- Inline-режим: в @BotFather выполни `/setinline` для бота, потом пиши `@бот ТЕГ` в любом чате.
- Языки: ru, en, uk, pl, tr (длинные тексты на pl/tr пока на английском). Валюты: RUB USD EUR UAH KZT PLN TRY GBP.

## Запуск на сервере
- Docker: `docker compose up -d --build` (база лежит в `./data`, бэкапы в `./data/backups`).
- Без Docker: `price-brawl.service` (systemd) с автоперезапуском.
- Бэкап базы: `BACKUP_HOURS` (по умолчанию раз в 24 часа), копия приходит первому админу.
- Ошибки бота приходят админам в Telegram (не чаще раза в минуту).
